Ananke Asylum is a runnable test site for the GoHugo Ananke theme.

This branch uses public-domain literature as structured fixture content. The content is intentionally organised into books, chapters, case files, authors, taxonomies, and source records so theme changes can be checked against realistic long-form material.

The initial corpus uses:

* Robert W. Chambers, *The King in Yellow*
* Charlotte Perkins Gilman, *The Yellow Wallpaper*

Run `npm run content:import` to generate the full text pages from Project Gutenberg source files.
